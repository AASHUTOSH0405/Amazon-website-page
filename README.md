# Amazon Front Page Clone

This project is a clone of the Amazon homepage created using HTML and CSS.

## Features
- Amazon-like navbar
- Search bar
- Product sections
- Hero banner
- Footer section
- Responsive layout

## Technologies Used
- HTML5
- CSS3

## Purpose
The purpose of this project is to practice frontend web development and improve HTML & CSS skills by recreating a popular e-commerce website layout.

## How to Run
1. Download or clone the project
2. Open amazon.html in any web browser

## Project Structure
├── index.html  
├── style.css
